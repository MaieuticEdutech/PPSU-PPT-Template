# PPSU PPT Designer (Engine)

Converts plain **raw content PPTs** (PPSU CDOE style) into **finished, PPSU-branded
decks** by reusing the designed layouts in `template/PPSU TEMPLATE.pptx` and swapping
in only the text — same engine as the REVA project, adapted for PPSU.

## How to run the website

Double-click **run.bat**. It starts:
- the Flask backend on port **5001** (`backend/app.py`)
- the frontend on port **8001** (`frontend/index.html`)

then opens http://localhost:8001/ . On the page:
1. Upload one or more **raw** PPTs (e.g. `RAW PPT1.pptx`).
2. Optionally upload a **template** — if you skip it, the bundled
   `template/TEMPLATE FOR PPSU.pptx` (283-slide design library) is used.
3. Generate → preview every slide → swap any slide's design → download.

Dependencies (one-time): `pip install -r backend/requirements.txt`
(needs `python-pptx`, `flask`, `flask-cors`; previews use PowerPoint or LibreOffice).

## Command-line build (no website)

```
cd backend
python analyze_template.py "..\template\PPSU TEMPLATE.pptx" > catalog.json
python engine.py --raw "..\..\PPSU RAW PPT\RAW PPT1.pptx" --template "..\template\PPSU TEMPLATE.pptx" --catalog catalog.json --out "..\FINAL PPTS\final.pptx"
```

## The template

`template/PPSU TEMPLATE.pptx` is generated by `build_template.py`. It is built on
top of a PPSU raw deck, so it carries the real PPSU master chrome (navy banner,
orange strip, PPSU logo) and contains 17 auto-detected designs:

- 2 / 3 / 4 / 5 / 6-point layouts (several looks per count, rotated so designs
  don't repeat across a unit)
- dedicated **Learning Objectives** and **Summary** designs (3–5 points), pinned
  by slide title and kept out of the general rotation

To add or change designs, edit `build_template.py` and re-run
`python build_template.py` — the catalog is rebuilt automatically on next upload
(cache is keyed by the template file's hash).

## What gets redesigned vs kept

A raw slide is redesigned when it is a heading + a clean list of points and the
template has a design with the **exact** point count. Everything else — title
slide, SME-placeholder slides (Introduction / Learning Objectives / Summary),
tables, prose slides, diagrams — is carried into the final deck unchanged, hosted
on the branded master so the navy banner and logo still appear.

## PPSU-specific engine changes (vs REVA)

- Headings inside fill-less auto-shapes (PPSU's "Text 8") are recognised.
- Rewrite fonts are FIXED: Calibri 24 pt (title) / 16 pt (subtitle, section
  subheadings and points). Text is never auto-shrunk; overlong text only
  raises a preview warning.
- Auto icons: the template carries icon designs (2–6 points, empty "Icon n"
  tiles). When EVERY point of a raw slide finds a matching icon (Iconify
  search API, needs internet; results cached in `backend/icon_cache/` for
  offline reuse), an icon design is used and the icons are dropped onto the
  tiles; otherwise a text-only design is used. Needs `pip install resvg-py`.
- Kept slides are hosted on the layout of the master that carries the logo, so
  they keep the PPSU banner chrome.
- No REVA-specific 2nd-slide typography special-case.
