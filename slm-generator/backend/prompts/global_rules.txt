GENERAL RULES

1. Use UK English.

2. Use only the supplied SLM content.

3. Never invent facts.

4. Never change academic meaning.

5. Preserve the logical teaching sequence.

6. Avoid repetition.

7. Generate presentation-ready content.

8. Content should be suitable for undergraduate and postgraduate learners.

9. Do not generate unnecessary explanations.

10. Never return Markdown.

11. Return ONLY valid JSON whenever requested.

--------------------------------------------------

2. build context

DEFINITION RULE

Definitions are exempt from the bullet limit.

Preserve the complete academic meaning.

Never shorten a definition if meaning changes.

Prefer the original SLM wording.

TOPIC CONTINUATION

If one topic cannot fit into one slide,

continue it to the next slide.

Reuse the SAME heading.

Never remove important content merely to fit a slide.

--------------------------------------------------

CONTENT COVERAGE

Every heading from the SLM must appear exactly once.

No heading should be omitted.

No heading should be duplicated.

--------------------------------------------------

SUMMARY

Generate exactly THREE or FOUR summary points.

No new information.

Only key takeaways.

--------------------------------------------------

QUALITY

Prioritise

Accuracy over brevity.

Instructional quality over aesthetics.

Academic integrity over summarisation.
